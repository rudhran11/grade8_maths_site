1. Multiplying a letter by itself

When the same letter is multiplied by itself, we write the letter with power 2. This is called a square.

a × a = a²

Examples:

  • x × x = x²
  • 5 × 5 = 25
  • 3a × 3a = 9a²
Remember: a² means a × a, not a × 2. For example, if a = 4, then a² = 4 × 4 = 16.

2. Expanding (x + y)(x + y)

Multiply each term in the first bracket by each term in the second bracket.

(x + y)(x + y) = x² + xy + xy + y²
(x + y)² = x² + 2xy + y²

Why is there 2xy? Because xy + xy = 2xy.

Worked example

(x + 3)²

= x² + 2(x)(3) + 3²

= x² + 6x + 9

Motion memory trick

➡️ First square + twice the product + last square.

Square the first term, double both terms multiplied together, then square the last term.

3. Formula for (a + b)²

(a + b)² = a² + 2ab + b²

Read it aloud: first squared, plus twice first times second, plus second squared.

Common mistake: (a + b)² is NOT a² + b². The middle term 2ab must be included.

Worked example

(a + 5)² = a² + 2(a)(5) + 25 = a² + 10a + 25.

4. Sign rules for multiplication

For multiplication, the signs combine like this:

First signSecond signAnswer signExample
+ + +(+3) × (+2) = +6
−−+(−3) × (−2) = +6
−+−(−3) × (+2) = −6
+−−(+3) × (−2) = −6
Same signs → positive (+)
Different signs → negative (−)

Use this for division too: same signs give a positive answer; different signs give a negative answer.

Example: (−4) × (−5) = +20. Two negative signs make a positive product.

5. Adding and subtracting signed numbers

Important: the “bigger number minus smaller number” trick is for adding numbers with different signs, not for multiplication.

Same signs: add, keep the sign

  • +4 + +3 = +7
  • −4 + −3 = −7
Same signs → add the sizes and keep their shared sign.

Different signs: subtract, keep the sign of the larger absolute value

  • −8 + 3 = −5
  • +8 + (−3) = +5
Different signs → subtract the smaller size from the larger size; use the sign of the number farther from zero.

Number-line idea

Positive numbers move right ➡️; negative numbers move left ⬅️. The result shows where you finish.

Do not mix up these rules:
Multiplication: same signs = positive, different signs = negative.
Addition: same signs = add; different signs = subtract and keep the sign of the larger absolute value.
