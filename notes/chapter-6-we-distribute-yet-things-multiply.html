Chapter 6: We Distribute, Yet Things Multiply

Quick revision notes: distributive property, algebraic identities, mental multiplication methods, and common mistakes.

1. Distributive Property

Multiply the term outside the bracket by each term inside the bracket. Keep the signs correct.

a(b + c) = ab + ac
(a + b)c = ac + bc
Example: 3(4 + 2) = 3 × 4 + 3 × 2 = 12 + 6 = 18
Example with a variable: 4(x + 3) = 4x + 12

Product of two brackets

(a + b)(c + d) = ac + ad + bc + bd
Example: (x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6

2. Important Algebraic Identities

Learn what each identity means, then practise choosing the correct one.

(a + b)² = a² + 2ab + b²
Example: 12² = (10 + 2)² = 100 + 40 + 4 = 144
(a − b)² = a² − 2ab + b²
Example: 98² = (100 − 2)² = 10000 − 400 + 4 = 9604
(a + b)(a − b) = a² − b²
Example: 98 × 102 = (100 − 2)(100 + 2) = 100² − 2² = 9996
Remember: The square of a difference still has + b²; only the middle term is negative.

3. Fast Multiplication Tricks

Multiply by 11

Use the distributive property: n × 11 = n × 10 + n.

3874 × 11 = 38740 + 3874 = 42614

For two-digit numbers, adding the digits in the middle can be a shortcut, but carry when the sum is 10 or more.

Multiply by 101

n × 101 = n × 100 + n
3874 × 101 = 387400 + 3874 = 391274

Multiply by 1001

n × 1001 = n × 1000 + n
234 × 1001 = 234000 + 234 = 234234

Numbers near 100

97 × 96 = (100 − 3)(100 − 4) = 10000 − 300 − 400 + 12 = 9312

4. Product Changes and Patterns

When numbers are written as sums or differences, expand each term and combine the results.

(a + m)(b + n) = ab + an + mb + mn
For (a + 1)(b + 1), the expansion is ab + a + b + 1.
(a + 1)(b − 1) = ab + b − a − 1

Pattern identity:

(a + b)² + (a − b)² = 2(a² + b²)

Use these to explain why products change when one or both numbers increase or decrease.

5. Like Terms and Correct Expansion

  • Like terms have the same variable part and powers: 2x + 5x = 7x.
  • x² and x are not like terms, so they cannot be combined.
  • When expanding a bracket, multiply every term and preserve positive and negative signs.
  • (x + 2)² is not x² + 4; it is x² + 4x + 4.
Worked example:
(x + 2)(x + 5)
= x² + 5x + 2x + 10
= x² + 7x + 10

6. Quick Practice Quiz

Try each question before opening its answer.

1. Expand 4(x + 3).
4x + 12
2. Expand (x + 2)(x + 3).
x² + 5x + 6
3. Calculate 99² using an identity.
99² = (100 − 1)² = 10000 − 200 + 1 = 9801
4. Calculate 48 × 11.
48 × 11 = 48 × 10 + 48 = 528
5. Expand (a − b)².
a² − 2ab + b²
6. Calculate 98 × 102 using an identity.
(100 − 2)(100 + 2) = 10000 − 4 = 9996

7. Simple Teaching Order

  1. Start with multiplication split into parts: 23 × 12 = 23 × (10 + 2).
  2. Teach the distributive property using numbers first, then variables.
  3. Practise expanding two brackets.
  4. Introduce the three identities and show one worked example for each.
  5. Finish with multiplication shortcuts and error-correction questions.
Teacher tip: Ask the student to explain why each term appears. Understanding the steps is more important than memorising the answer.
